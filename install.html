Hey Siri, stupid idea

1. Tap the yellow button. Shortcuts opens. Tap Add Shortcut.

Install shortcut

2. Then say "Hey Siri, Stupid Idea", talk, and pause. It emails the idea to your ideas inbox.

If the yellow button says import failed, use this one, then open the downloaded file from Safari's downloads (⬇ icon) and tap Add Shortcut:

Download file instead

If Settings asks, turn on Settings → Shortcuts → Allow Sharing Large Amounts of Data / Allow Untrusted Shortcuts (only needed for untrusted files).
